# Where is Krecik?

A classroom listening game: students track a hidden mole across a grid, then the teacher reveals where he stopped.

Public, bilingual (`en` / `pl`), no accounts or database.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The app redirects to `/en` or `/pl`.

| Script | Purpose |
| --- | --- |
| `npm run dev` | Turbopack dev server |
| `npm test` | Vitest (movement rules + locale UI) |
| `npm run build` | Production build |
